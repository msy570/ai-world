# AI World

Prototype de sandbox autonome conçu pour des vidéos de simulation.

## Fonctionnalités actuelles

- Grande carte 4200×2800
- Caméra avec zoom à la molette
- Déplacement avec clic droit + glisser
- Biomes éditables : plaine, forêt, désert, neige, eau
- PNJ avec noms aléatoires
- Personnalités : calme, agressif, avide, sociable, explorateur
- Stats : vie, faim, âge, vitesse, agressivité
- Objets : nourriture, bois, or
- Inventaire individuel
- Donner des objets à un PNJ
- Ajouter 1 ou 50 PNJ
- Simulation autonome
- Vitesse ×1 / ×3 / ×8 / ×20

## Lancer

Ouvre `index.html` dans ton navigateur.

Pour GitHub Pages :
Settings → Pages → Deploy from a branch → `main` → `/root`.
